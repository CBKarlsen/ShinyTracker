# Product

## Register

product

## Users
Pokémon Shiny Hunters, ranging from casual collectors to hardcore hunters who run multiple consoles, track pace, and log phase counts. They require high-contrast, eye-strain-free dark interfaces during long, multi-hour hunting sessions.

## Product Purpose
ShinyTracker is a web application for tracking Pokémon shiny hunts, managing encounter counters, and building a shiny Living Dex. The goal is to provide a seamless, delightful, and keyboard-efficient tool that replaces manual notebooks or counter apps.

## Brand Personality
Sleek Gamer-Dashboard: dark, neon accents, high contrast, clean typography, with the extreme attention to detail and polish found in tools like Linear and Raycast.

## Anti-references
Generic SaaS layouts (e.g. boring white cards, plain shadows, uninspired text labels, unnecessary multi-step modals). Avoid bright themes that strain eyes during late-night hunts.

## Design Principles
1. **Focus on the Hunt**: The active hunt counter is the primary actor. Interactions must be fast, keyboard-centric, and clear.
2. **Immersive Gamer Dark-Mode**: A dark theme utilizing tinted neutrals and neon accents that is optimized for long sessions.
3. **Data Richness without Clutter**: High-density information (pace, odds, milestones) displayed cleanly using strong hierarchy and typography.
4. **Action Feedback**: Every user interaction (encounters, phases, game selection) must have immediate and clear visual feedback.

## Accessibility & Inclusion
- Optimized for keyboard accessibility (hotkeys for increments, modal triggers, navigation).
- WCAG AA color contrast compliance, especially for dark mode text readability.
- Clear visual indicators that do not rely solely on color for status.
