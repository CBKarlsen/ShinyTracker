3Two new pillars — Team and Reference

Green = Team — a roster with coverage and holes computed live, a fourth mode alongside Hunt, Nuzlocke and Dex. It is entered from the run: the party sheet's coverage block opens it, and a gym checkpoint opens the matchup with that leader loaded. Reference is not a mode. It is a search sheet over whatever you were doing, reachable from every header — lookups happen mid-task, so a tab would cost you your place and strand the "your team can learn" line in 3d. That keeps the nav at four labelled slots.

2Separating Nuzlocke from shiny — mode is the container, colour is the signal

The glass bar from 1c becomes the mode switch, and each mode owns its accent: gold = shiny only (your existing One Sparkle Rule), blue = Nuzlocke, parchment = Dex. So a run screen never shows gold and a hunt screen never shows a level cap — you can tell which mode you're in from the corner of your eye. Two dexes sit behind one Dex tab: Living Dex counts species you own in any form, Shiny Dex counts shinies only and is the one wired to hunts.
